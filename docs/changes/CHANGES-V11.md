# Retraites 2070 — passe complète V11

## Architecture
Avant : 19 sections qui s'empilaient (faits, thèse, jeux, simulateurs) sans fil conducteur. Après, cinq temps.

| Temps | Sections | Question posée |
|---|---|---|
| 1. Les faits | hero, démographie, argent, ailleurs, partis | Où en est-on, que font les autres, que proposent les partis ? |
| 2. Notre position | pivot, **fiche de paie**, trois étages, fonctionnement du fonds, bilan, personas | Pourquoi changer, quoi proposer, qui y gagne, où ça échoue ? |
| 3. Les ateliers | intro, financement, intérêts composés, transition, simulateur, leviers | Et si on chiffrait ? |
| 4. Conclusion | ce que nous défendons | |
| 5. Pièces | méthode, sources | |

- **La fiche de paie ouvre la thèse** : elle est notre premier argument (la retraite pèse surtout sur le travail), pas un « jeu » parmi d'autres.
- **« Trois étages » précède « Comment le fonds fonctionne »** : le principe d'abord, la mécanique ensuite.
- **« Les ateliers »** regroupe tous les outils derrière une même intro. Nav : Les faits · Ailleurs · Les partis · Notre proposition · Les ateliers · Les sources.

## Voix
- Le site parle depuis sa position à partir du pivot : « nous prenons position », « notre proposition », « nous les gardons ».
- **Plus aucune mention d'« objections de gauche »** : le bloc devient « Ce que le fonds ne fait pas », écrit à la première personne du projet.
- Titres descriptifs, sans slogan ni phrase « à effet » : « Financer les retraites jusqu'en 2070. », « Ce que font les autres pays. », « Les retraites pèsent sur la fiche de paie. »
- Plus de méta-commentaire (« une thèse se juge à ses risques », « on compare des principes, pas des montants »). La phrase dit ce que fait le tableau.
- Le hero donne les chiffres (14,1 % du PIB, 62 pour 100) au lieu de les annoncer.

## Contenu retouché
- Bilan : « Ce que ça apporte » / « Ce que ça coûte » / « Ce que le fonds ne fait pas ».
- « Ailleurs » : lecture explicite : aucun de ces pays n'a un fonds sans rente pétrolière ni cotisations dédiées, « c'est ce qu'il nous faut inventer ».
- Fiche de paie : « environ 28 % du brut » (vérifié sur 1 823 €, 3 000 € et 6 000 €).

## Pas fait
- Textes d'origine non réécrits : fiches de sources, cartes de garde-fous, comparateur des partis, leviers du laboratoire, MODEL.md, EDITORIAL-V4.md.
- Les trois ateliers du bas (registre, simulateur, leviers) font en partie doublon avec le jeu de financement : à fusionner en un seul outil.
- Design non refait (même identité visuelle). Bugs mobiles, petits textes et « choc au début » toujours ouverts.
